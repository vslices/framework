# VSlices — 0.1.0-preview.1

VSlices is a modular C# framework exploring domain modeling, functional workflows, grounding, and presentation. These packages target .NET 10 and are **experimental prereleases**: APIs may change without compatibility guarantees.

Source and issue tracker: https://github.com/vslices/framework

The package family is versioned together. Reference only the components you need; NuGet resolves their package dependencies. `VSlices` is the proposed root package ID, subject to NuGet.org availability and ownership verification before public release.

This preview deliberately **does not distribute the experimental VSlices.Spaces analyzer**. Analyzer behavior remains available for controlled source-repository testing only.
